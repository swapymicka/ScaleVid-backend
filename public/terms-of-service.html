2 Description du service

ScaleVid est une application web permettant aux utilisateurs de :

  • Se connecter à leurs comptes TikTok et/ou YouTube via OAuth 2.0
  • Télécharger des fichiers vidéo et renseigner leurs métadonnées (titre, description, hashtags)
  • Publier automatiquement des vidéos sur les plateformes sélectionnées via leurs API officielles

ScaleVid agit en tant qu'intermédiaire technique entre vous et les plateformes tierces. ScaleVid n'est pas affilié à TikTok, ByteDance, YouTube, Google, ou toute autre plateforme tierce.
